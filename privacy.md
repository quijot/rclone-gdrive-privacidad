# Política de privacidad — rclone Google Drive

**Última actualización:** 14 de octubre de 2026

Esta aplicación es de uso personal y utiliza rclone para sincronizar archivos entre Google Drive y un equipo local.

## Datos y acceso

La aplicación utiliza la API de Google Drive para acceder a los archivos y carpetas de la cuenta autorizada por el usuario. El acceso se utiliza exclusivamente para realizar las operaciones de sincronización configuradas por el propio usuario.

## Almacenamiento y transmisión

Los archivos se sincronizan entre Google Drive y el equipo local del usuario. No se recopilan ni se venden datos personales con fines publicitarios. Este sitio web no recopila información personal mediante formularios ni utiliza cookies propias de seguimiento.

## Compartición de datos

La aplicación no comparte información con terceros para fines comerciales. Google procesa los datos conforme a sus propias políticas y condiciones.

## Seguridad

Las credenciales y los tokens de acceso deben almacenarse de forma segura en el equipo del usuario. El usuario puede revocar los permisos concedidos desde la configuración de seguridad de su cuenta de Google.

## Contacto

Para consultas sobre esta aplicación, contactá al responsable a través del medio por el que se distribuyó esta política de privacidad.
